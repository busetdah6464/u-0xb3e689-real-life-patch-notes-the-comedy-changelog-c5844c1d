# Real-Life Patch Notes: The Comedy Changelog

Entry for [Real-Life Patch Notes: The Comedy Changelog](https://make.fun/bounty/u-0xb3e689-real-life-patch-notes-the-comedy-changelog-c5844c1d) on make.fun.

One single-line patch note, at most 160 characters, for a bug in real
life: yawning in a meeting silently notifies the whole room that you
are bored. Written in the terse register of a real release note, with
the version tag up front and the sting at the end.

`entry.py` is the readable source; `main.py` is the kit-packed entry
(`node <kit>/cli/makefun.mjs compress entry.py --out main.py`). Either
writes the line to `/output/entry.txt`, deterministically.

Run it with `python3 main.py`; run it twice and the output is byte-identical.
